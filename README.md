# MIRA SPA — Luxury Wellness Sanctuary Website

A complete, premium, production-quality 4-page website for **Mira Spa**, a luxury wellness and spa sanctuary in Victoria Island, Lagos, Nigeria.

---

## ✦ Key Features

- **Cinematic Revolution Slider-Style Hero**: 4 full-bleed atmospheric slides with slow Ken Burns image zoom, staggered typography entrance, progress bar indicator, slide counter, and arrow navigation.
- **Warm Editorial Visual Direction**: Curated palette of Warm Ivory (`#F4EBDD`), Soft Cream (`#E8DCC8`), Deep Espresso (`#2E1C13`), Muted Gold (`#B8955A`), Natural Walnut (`#6B4228`), and Warm White (`#FBF8F2`).
- **Typography**: High-contrast pairing of *Cormorant Garamond* / *Playfair Display* with clean modern *Manrope*.
- **Integrated Asset Library**: 17 high-resolution professionally art-directed spa images, incorporating all primary reference images.
- **Global Interactive Booking System**:
  - Global modal accessible from any page
  - Interactive appointment form with service selector, date picker, time windows, and therapist preference
  - Instant luxury booking receipt confirmation state with reference code generator
- **Floating WhatsApp Concierge**: Instant direct chat widget with online status indicator.
- **Interactive Service Directory**: Filterable directory across 5 categories (*Massage Therapy, Facial & Skincare, Body Rituals, Beauty & Nails, Spa Experiences*) with 20+ treatments, durations, editable Naira placeholders, and etiquette FAQ accordion.
- **SEO & Structured Data**: Complete Open Graph metadata and Schema.org `DaySpa` JSON-LD structured data.

## ✦ Running Locally

### Option 1: Direct File
Open `index.html` in any modern web browser.

### Option 2: PowerShell Local Server
Run the included lightweight static server:
```powershell
powershell -ExecutionPolicy Bypass -File .\server.ps1 -Port 8080
```
Then visit: `http://localhost:8080/`
